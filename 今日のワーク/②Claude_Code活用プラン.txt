============================================================
     Claude Code 活用プラン ― 齋藤史枝
============================================================
作成日: 2026年3月31日

------------------------------------------------------------
■ 活用の目的
------------------------------------------------------------
看護系大学教員としての業務効率化と、
苦手分野（マネジメント・スケジューリング）の克服、
そしてAI動画作成という新しい挑戦を実現する。

============================================================
 PLAN 1: 授業・研修の企画をAIで加速する
============================================================
【現状】研修の企画・設計は得意だが、時間がかかる
【活用法】
  ・シミュレーション研修のシナリオ案をClaudeに壁打ち
    例: 「急性期看護のシミュレーションシナリオを3パターン
         作って。対象は3年生、60分間、振り返り含む」
  ・ルーブリック（評価基準）のたたき台をAIで作成
  ・研修後のアンケート集計結果の分析を依頼
【効果】企画にかかる時間を半分に → 質の向上に時間を使える

============================================================
 PLAN 2: 苦手なスケジュール管理をAIで仕組み化
============================================================
【現状】事前にスケジュールを立ててメンバーと共有するのが苦手
【活用法】
  ・プロジェクト情報をClaudeに伝えて、
    スケジュール案＋マイルストーンを自動生成
    例: 「8月のOSCE準備、関係者5名、準備期間3ヶ月。
         スケジュールと役割分担を作って」
  ・週次メールの下書きをAIに作ってもらう
    → メンバーへの進捗共有が楽になる
  ・会議のアジェンダ・議事録テンプレートを自動生成
【効果】共有の「心理的ハードル」が下がる

============================================================
 PLAN 3: 教材・資料づくりを効率化する
============================================================
【現状】授業資料や配布物の作成に時間を取られる
【活用法】
  ・講義ノートの要約・学生向けハンドアウトの作成
  ・国家試験対策の練習問題を自動生成
    例: 「成人看護学の国試レベル問題を10問、解説付きで」
  ・英語論文の要約・翻訳サポート
  ・実習記録のコメント例文を生成
【効果】ルーティンワークの時間を大幅削減

============================================================
 PLAN 4: AI動画作成への第一歩
============================================================
【現状】AIで動画を作ってみたいが、何から始めればいいかわからない
【活用法】
  Step 1: Claudeに動画の構成・台本を作ってもらう
    例: 「手指衛生の手順を解説する3分間の教育動画の台本を
         作って。対象は看護学生1年生」
  Step 2: 台本をもとにAI音声生成ツールでナレーション作成
  Step 3: AI画像生成で図解・イラストを作成
  Step 4: 動画編集ツールで組み合わせる
【おすすめツール】
  ・台本作成     : Claude
  ・AI音声       : VOICEVOX / ElevenLabs
  ・AI画像       : Canva AI / DALL-E
  ・動画編集     : Canva / CapCut
  ・AI動画生成   : Runway / Pika
【効果】看護技術の教育動画を自作 → 反転授業に活用

============================================================
 PLAN 5: マネジメント力をAIで補強する
============================================================
【現状】チームのマネジメントが苦手
【活用法】
  ・困った場面をClaudeに相談して対応案をもらう
    例: 「メンバーの意見が割れています。状況は○○。
         どう進めるのがよいですか？」
  ・1on1ミーティングの質問リストを生成
  ・チームビルディングのワークショップ案を相談
  ・年間計画のたたき台を一緒に作る
【効果】一人で抱えず、AIを「思考のパートナー」にする
